# 气瓶年检规则依据（Portal 客服）

## 口径说明
- 本项目在客服“年检时间查询”中采用 **监管法检周期** 口径。
- 当前实现为后端可配置规则表，版本：`CN_TSG23_2021_V1`。
- 计算结果用于客服提醒与预约引导，最终执行以属地监管和检验机构结论为准。

## 当前实现口径（MVP）
- 适用场景：瓶装配送、换瓶订单。
- 规格映射：`5kg / 15kg / 45kg`。
- 定期检验周期：`48 个月`（4 年）。
- 设计使用年限参考：`96 个月`（8 年）。
- 经安全评估允许延长上限参考：`144 个月`（12 年）。

> 说明：实际是否可延长、如何认定，以检验机构与监管最新要求为准；系统仅提供规则化提醒。

## 计算逻辑
1. 查询用户历史气瓶相关订单。
2. 若有多单，先让用户选择订单（编号或订单号）。
3. 取计算基准日（优先级）：
   - `last_inspection_date`
   - `next_inspection_date` 反推
   - 订单 `eta_end`
   - 订单 `created_at`
4. 按规格规则计算 `next_inspection_date`。
5. 返回建议年检日、规则版本、依据与提示文案。

## 后续更新策略
- 规则变更先更新 `customer_portal/constants.py` 与 `inspection_rules.py`。
- 同步更新本文件中的版本号和来源。
- 新增省市差异口径时，按“地区规则覆盖默认规则”扩展，不改现有接口。
