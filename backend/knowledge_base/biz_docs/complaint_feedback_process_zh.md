content:
- 线上体验类投诉或建议可直接提交，无需强制关联订单。
- 订单服务类投诉建议关联订单号，便于快速定位配送或上门记录。
- 提交后会生成反馈编号，可查询状态（待处理、处理中、已处理）。
- 高风险安全投诉应优先转安全应急流程，先保障人身安全。
- 回复用户时应先共情，再说明处理步骤与预期时效。
