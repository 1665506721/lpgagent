- 当前平台参考价（MVP）：5kg 为 60 元，15kg 为 120 元，45kg 为 280 元。
- 价格可能随采购、运力和合规成本变化做阶段性调整。
- 用户问“今天多少钱”时，先给规格价，再提示“以下单页实时价格为准”。
- 用户未给规格时，先给三档规格价，再追问需要哪种规格与数量。
- 如用户要看历史走势，可说明通常是小幅调整，不承诺历史价复用。
