content:
- 自助下单推荐 3 步：选择服务类型、填写地址与时间、确认并支付。
- 客服代下单流程：先收集信息，再生成订单摘要，用户确认后才执行。
- 关键信息通常包括：服务类型、规格数量、地址、联系人、预约时间、是否加急。
- 支付采用“先支付后成立”的状态逻辑，未支付订单会在时限后过期。
- 若用户说“先报价再下单”，先提供估算，再进入确认下单环节。
